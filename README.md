# Зелений Сад — інтернет-магазин саджанців

Node.js (>= 22.13) + Express + SQLite (вбудований модуль `node:sqlite`).

## Запуск

```bash
npm install
npm run create-admin -- admin@example.com НадійнийПароль "Ім'я"
npm start            # http://localhost:3000
```

| Сторінка | Адреса |
|---|---|
| Магазин | `/` |
| Сторінка лота | `/product?id=N` |
| Вхід / реєстрація | `/login`, `/register` |
| Особистий кабінет | `/account` |
| Адмін-панель (каталог, замовлення, покупці) | `/admin` |

## Налаштування (.env)

Скопіюйте `.env.example` у `.env`:

- `NP_API_KEY` — ключ API Нової Пошти (необов'язковий: пошук міст і відділень працює і без нього).
- `UKRPOSHTA_TOKEN` — токен адресного класифікатора Укрпошти (видається за договором).
  Без нього покупець вводить індекс відділення Укрпошти вручну.

## Дані

Усе зберігається в папці `data/`: база `shop.db` і фото лотів `uploads/`. Для резервної копії
достатньо скопіювати цю папку. Нові колонки в базі додаються автоматично під час запуску.

`npm run create-admin -- <email>` — зробити існуючого користувача адміністратором.

У продакшні запускайте з `NODE_ENV=production` за HTTPS (cookie сесії отримує прапорець `Secure`).
